# Unraid Template: MCP Obsidian

![GitHub Repo stars](https://img.shields.io/github/stars/MarkusPfundstein/mcp-obsidian?style=social)
![Unraid Compatible](https://img.shields.io/badge/Unraid-Compatible-orange?logo=unraid)

Unraid Docker template for the MCP-server for Obsidian.

This container connects your local Obsidian Vault to AI agents (like Open WebUI, Claude, or Gemini) using the Model Context Protocol (MCP). It acts as a middleman, allowing LLMs to search, read, and write directly into your notes.

## 🚀 Prerequisites

1. You must have the **Obsidian App** running on a computer or server.
2. Inside Obsidian, install the Community Plugin **[Local REST API](https://github.com/coddingtonbear/obsidian-local-rest-api)**.
3. Go to the plugin settings in Obsidian, enable "Advanced Settings" and change the Binding Host from `127.0.0.1` to the actual IP address of your machine (e.g., `192.168.20.50`).
4. Note down the **API Key** generated by the plugin.

## 🛠️ Installation on Unraid

To use this template, simply add it via the **Docker** tab in Unraid:

1. Scroll to the bottom of the Docker page and click **Add Container**.
2. Switch to **Advanced View**.
3. Under **Template URL**, paste the following link:
   ```text
   https://raw.githubusercontent.com/junkerderprovinz/mcp-obsidian-unraid/main/mcp-obsidian.xml
   ```
4. Provide the following parameters:
   - **Network Type:** `br0` (or whichever custom network/VLAN you use).
   - **Fixed IP address:** Assign an IP (e.g., `192.168.20.25`).
   - **Obsidian API Key:** Paste the API key from the Local REST API plugin.
   - **Obsidian Host URL:** Enter the IP where Obsidian is running (e.g., `http://192.168.20.50:27124`).
   - **MCP Port:** `9999` (Default).
5. Click **Apply**.

## 🔌 Connecting to Open WebUI

1. Open your Open WebUI Admin Panel.
2. Go to **Admin Settings** -> **Tools** -> **Manage Tool Servers**.
3. Click **Add Connection**.
4. Enter the URL of your new MCP container (e.g., `http://192.168.20.25:9999`).
